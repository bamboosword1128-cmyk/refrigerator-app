# 冷蔵庫説明ナビ 公式仕様DB

家電量販店の接客で、メーカーをまたいだ機種比較と「売り分け」を短時間で行うための静的Webアプリです。外部ライブラリは使用していません。

## 現在の収録範囲

- メーカー: パナソニック、日立、三菱電機、東芝、シャープ、AQUA、Hisense、Haier、アイリスオーヤマ、TWINBIRD
- 機種数: 157機種（追加画像8枚に記載された144型番を全件収録し、既存の比較機種も保持）
- 位置づけ: 指定型番を横断検索・比較できる接客用データベース
- 一次情報: `../冷蔵庫カタログ_2025_2026/` のメーカー公式カタログ15件と、メーカー公式仕様ページ
- 出典追跡: 機種ごとにカタログIDと確認ページを保持し、詳細画面に表示
- 表記揺れ: 入力型番と公式型番を別名として保持（例: `IRS-NFX43A` → `IRSN-FX43A`、TWINBIRDの色記号付きSKU）
- 未確認項目: 「記載がない＝非対応」とせず、`null` と `false` を区別して `－ 未確認` と表示
- 調査状況: 公式一次資料で確定できなかったセルを、必要資料の仮説付きレポートとCSVに出力

## 主な機能

- 型番・メーカー・シリーズ・機能名のキーワード検索
- メーカー、タイプ、発売年、容量、幅、ドア方式、レイアウト・重視点、年間消費電力量の複合絞り込み
- 同じグループ内はOR、異なるグループ間はANDの絞り込み
- 最大7機種の横並び比較と「違いのみ表示」
- 12カテゴリの折りたたみ比較と、容量・幅・消費電力量などのベスト値強調
- 年間電気代の自動計算（電力単価31円/kWh。`comparison.electricityRateYenPerKwh` で変更可）
- 商品カードのロゴ、容量、幅、発売年、レイアウトバッジ、おすすめ表示
- 機種ごとの「おすすめ」「強み」「注意点」と、メーカー別の売り分け早見
- 機種詳細、公式URL、カタログ出典の表示
- 未確認項目のメーカー別・項目別・型番別レポートとCSVダウンロード
- 360px幅から使えるモバイル向けカード比較

## ローカル確認

プロジェクト直下で次を実行し、`http://localhost:4173` を開きます。

```sh
python3 -m http.server 4173 -d app
```

## データ検証

```sh
node scripts/validate-data.mjs
```

独自検証では、ID重複、参照整合性、数値の想定範囲、`available` の型、出典トレース、既知/不明セル数を確認します。

## ファイル構成

- `app/index.html`: 画面構造
- `app/styles.css`: レスポンシブ表示を含むスタイル
- `app/app.js`: 検索、絞り込み、詳細、比較の処理
- `app/data.js`: ブラウザで読み込む機種データ
- `app/unresolved.html`: 未確認項目と追加で必要な情報源のブラウザ版レポート
- `app/unresolved-fields.csv`: 未確認セルの全件明細
- `app/assets/logos/`: 作業フォルダ内のメーカーロゴ（未提供メーカーは名称をフォールバック表示）
- `scripts/validate-data.mjs`: 冷蔵庫比較データの品質検証
- `../refrigerator-spec.json`: 生成元の構造化データ
- `../tmp/target-models.tsv`: 追加画像8枚から転記した144型番の照合表
- `../tmp/expand-refrigerator-db.mjs`: 公式仕様の正規化・DB統合スクリプト
- `../tmp/enrich-refrigerator-features.mjs`: 公式機能表の反映と未確認項目レポート生成
- `UNRESOLVED_FIELDS.md`: 未確認項目の集計と、追加情報源に関する仮説
- `netlify.toml`: Netlify公開設定

データを追加・修正する際は `refrigerator-spec.json` を先に更新し、メーカー公式カタログ・製品ページの出典を残してください。`app/data.js` はその正規化済みデータをブラウザ用に書き出したものです。
